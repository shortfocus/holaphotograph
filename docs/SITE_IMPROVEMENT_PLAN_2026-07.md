# 사이트 개선·고도화 계획 (2026-07)

**작성일:** 2026년 7월 3일  
**근거:** 고객 미팅 피드백 정리  
**목표:** 브랜드 포지셔닝을 **「리코 GR 전문 강사·콘텐츠」** 중심으로 재정렬

---

## 1. 개요

고객 미팅에서 수집한 홈페이지 개선 의견을 현재 코드베이스 기준으로 우선순위·단계별 실행 계획으로 정리한 문서입니다.

기술적으로는 **콘텐츠·UI 교체(빠름)** → **구조 변경(중간)** → **외부 API·신규 기능(느림)** 순으로 진행하는 것을 권장합니다.

### 현재 홈 구조 (참고)

```
팝업(비활성) → Hero(3슬라이드) → YouTube 롱폼 → 블로그(정적 6) → Shorts → 누적 성과 → 협업 문의
```

### 주요 관련 파일

| 영역 | 파일 |
|------|------|
| 홈 UI | `src/pages/index.astro` |
| 레이아웃·네비·플로팅 바 | `src/layouts/Layout.astro` |
| API 클라이언트 | `src/lib/api.ts` |
| Worker (YouTube, 강의신청, 리뷰) | `worker/src/index.ts` |
| 수강생 후기 | `src/pages/reviews/index.astro` |
| 관리자 강의 신청 | `src/pages/admin/lecture-signups.astro` |

## 2. 요구사항 원문 정리

### 히어로 영역

- 문구 수정 → **「리코」GR 카메라 강조**
- 사이트 메인 히어로 영상 → **리코 영상으로 대체**
- 백그라운드 이미지 → **리코 카메라 적용** (연출 참고: [후지필름 제품 페이지](https://fujifilm-korea.co.kr/products/id/1334))
- **2번, 3번 슬라이드 삭제**
- 히어로 바로 하단 → **수강생 후기 마퀴**

### 상단 메뉴바

- 고객 후기 → **수강생 후기**
- **협업 및 광고 문의** 상단 메뉴에서만 제거
- **작가 갤러리** 메뉴 추가 (DB 이미지 한도 확인 필요)

### 1번 섹션

- 유튜브 영상 주제를 **리코 시리즈**로 배치 변경

### 우측 영역

- **강의 신청 버튼** 추가

### 플로팅 강의 소식 받기

- 인풋 포커스 시 영역 높이 확장 → **리코 / 후지필름 / 소니** 선택

### 관리자

- 강의 신청 목록 → **엑셀 다운로드** 기능

### 숏폼 섹션

- YouTube API 대신 **Instagram API** 적용

### 로고

- 파일 수령 후 교체

### 추후

- **리코 행사 데이터 연동**

## 4. Phase별 실행 계획

### Phase 1 — Quick Wins (1주차, 즉시 체감)

고객이 사이트에 들어왔을 때 **「리코 사이트」**로 느껴지게 하는 작업.

#### 1-1. 히어로 영역 단순화

**현재:** 3슬라이드 (리뷰 플랫폼 / 강의 안내 / 고객 리뷰)

**변경:**

- 슬라이드 **1개만** 유지 (2·3번 삭제)
- 카피: 리코 GR 카메라 강조 문구로 교체
- 배경: 리코 카메라 이미지 적용
- 메인 영상: 리코 관련 YouTube 영상으로 교체

> 후지필름 제품 페이지 링크는 **레이아웃·연출 참고용**이며, 실제 에셋은 리코용으로 준비.

**선행 확인:** 리코 히어로 영상 URL, 배경 이미지(고해상도), 확정 카피 문구

**작업 파일:** `src/pages/index.astro`, `src/styles/global.css` (캐러셀 3슬라이드 → 1슬라이드 조정)

#### 1-2. 상단 메뉴바

| 변경 | 내용 |
|------|------|
| 고객 후기 → **수강생 후기** | `Layout.astro` + `/reviews` 페이지 타이틀 |
| **협업 및 광고 문의** 상단 메뉴 제거 | 하단 `#about` 섹션은 유지 가능 |
| 로고 교체 | 파일 수령 후 `public/` 교체 |

**작업 파일:** `src/layouts/Layout.astro`, `src/pages/reviews/index.astro`

#### 1-3. 유튜브 1번 섹션 (롱폼)

- `worker/src/index.ts`의 `YOUTUBE_LONG_ORDER` 및 필터를 **리코 시리즈 영상 ID** 기준으로 재배치
- 섹션 제목·설명도 리코 중심으로 수정

**선행 확인:** 노출할 리코 영상 YouTube ID 목록 (우선 5~6개)

**작업 파일:** `worker/src/index.ts`, `src/pages/index.astro`

---

### Phase 2 — 전환·신뢰 강화 (2주차)

#### 2-1. 히어로 바로 아래 수강생 후기 마퀴

```
[Hero] → [수강생 후기 마퀴] → [YouTube 롱폼] → ...
```

- `GET /api/reviews`에서 `review_type=lecture` 승인 후기 사용
- 가로 무한 스크롤 마퀴 (제목·닉네임·일부 본문)
- 후기 없을 때 fallback UI

**기술:** API는 이미 있음. 홈에 신규 섹션 + CSS 애니메이션 추가.

**작업 파일:** `src/pages/index.astro`, `src/styles/global.css`

#### 2-2. 우측 강의 신청 버튼

- 히어로 또는 화면 우측 고정 FAB 형태 검토
- 클릭 시 공지 상세 또는 강의 신청 폼으로 이동
- 기존 `POST /api/lecture-signup` 또는 공지 링크 재사용

**선행 확인:** 버튼 클릭 시 이동 대상 (공지 URL? 별도 폼?)

**작업 파일:** `src/pages/index.astro` 또는 `src/layouts/Layout.astro`

#### 2-3. 플로팅 강의 소식 받기 확장

**현재:** 이메일 1개 입력 (`Layout.astro` → `POST /api/lecture-signup`)

**변경:** 포커스/호버 시 높이 확장 → **리코 / 후지필름 / 소니** 선택

**필요 작업:**

- DB: `lecture_signups`에 `interest_brand` 컬럼 추가 (마이그레이션)
- API: 신청 body 확장
- 관리자 목록: 브랜드 컬럼 표시

**작업 파일:** `worker/migrations/`, `worker/src/index.ts`, `src/layouts/Layout.astro`, `src/pages/admin/lecture-signups.astro`

---

### Phase 3 — 운영·콘텐츠 확장 (3~4주차)

#### 3-1. 관리자 강의 신청 엑셀 다운로드

**현재:** 읽기 전용 테이블 (`admin/lecture-signups.astro`)

**추가:** CSV/XLSX 다운로드 버튼 (클라이언트 CSV 또는 서버 생성)

Phase 2 브랜드 컬럼 반영 후 함께 배포 권장.

**작업 파일:** `src/pages/admin/lecture-signups.astro`

#### 3-2. 작가 갤러리 (신규)

**현재:** 갤러리 모듈 없음. 후기 이미지는 R2 `reviews/` (5MB, jpeg/png/gif/webp)

**설계 필요 사항:**

| 항목 | 확인 필요 |
|------|----------|
| 이미지 저장 | R2 신규 prefix `gallery/` vs 기존 업로드 API 확장 |
| DB | `gallery_images` 테이블 (title, image_url, sort_order, created_at) |
| 업로드 주체 | 관리자만 vs 작가 셀프 업로드 |
| 용량 한도 | R2 버킷 전체 / 이미지당 5MB(후기와 동일) 검토 |
| 노출 방식 | 그리드 / 라이트박스 / 무한 스크롤 |

**권장:** 1차는 **관리자 업로드 + 그리드 갤러리** MVP → 이후 작가 셀프 업로드

**작업 파일:** 신규 페이지 `src/pages/gallery/`, Worker API, 관리자 업로드 UI

---

### Phase 4 — 장기·리스크 높음 (별도 기획)

#### 4-1. 숏폼 → Instagram API

**현재:** YouTube Data API → 60초 이하를 Shorts로 분류 (`worker/src/index.ts`)

**전환 시 고려:**

- Instagram Graph API: **비즈니스/크리에이터 계정** + Meta 앱 심사
- 토큰 갱신(60일), Rate limit, 미디어 URL 만료
- Worker에 Instagram fetch + KV 캐시 신규 구현
- YouTube Shorts 섹션을 Instagram Reels로 **완전 대체** vs **병행** 결정 필요

**권장:** Instagram 계정·API 접근 권한 확보 전까지 **YouTube Shorts 유지**. 권한 확보 후 Phase 4로 분리.

#### 4-2. 리코 행사 데이터 연동 (추후)

- 외부 API / 스프레드시트 / 수동 입력 방식 미정
- 공지사항·메인 팝업과 연동 가능성 검토
- 요구사항·데이터 소스 확정 후 별도 스펙 작성

## 8. 결론

1. **먼저 할 것:** 히어로 리코화 + 메뉴 정리 + 유튜브 큐레이션 → 브랜드 전환 효과 최대
2. **바로 이어서:** 수강생 후기 마퀴 + 강의 신청 CTA → 전환율 개선
3. **운영과 함께:** 플로팅 바 브랜드 선택 + 엑셀 다운로드
4. **별도 스펙 후 진행:** 작가 갤러리, Instagram API, 리코 행사 연동
